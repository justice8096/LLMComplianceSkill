# Compliance Configuration Template

Template for creating the compliance-config.json file.

## Required Fields

- **project_name**: Name of the AI/LLM system
- **organization**: Organization name
- **jurisdictions**: Array of applicable jurisdiction codes
- **risk_classification**: AI system risk level
- **model_info**: Model name, version, provider

## Optional Fields

- **deployment_date**: Planned or actual deployment date
- **data_sources**: Description of training/inference data sources
- **human_oversight**: Human oversight mechanisms in place
